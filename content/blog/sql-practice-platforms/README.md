# Free SQL practice platforms for data engineering

SQL is the core skill for data engineering. These platforms are free and
useful for practicing the SQL that data engineers actually write: window
functions, CTEs, joins, aggregation, SCD, CDC, and data modeling.

| Platform | Focus | Level | Good for DE? | Free |
|---|---|---|---|---|
| [Oracle Dev Gym](https://devgym.oracle.com/) | Advanced SQL, analytic/window, performance, indexing, execution plans | Beginner to Advanced | 5/5 | Yes |
| [DataDriven.io](https://datadriven.io/problems) | SQL for DE specifically: SCD, dedup, CDC, transformation, window, data modeling | Beginner to Advanced | 5/5 | Yes |
| [DataLemur](https://datalemur.com/questions?category=SQL) | Interview SQL: window, CTE, joins, aggregation | Beginner to Advanced | 4/5 | Yes* |
| [SQLPractice.in](https://www.sqlpractice.in/) | Interactive SQL, window, CTE, interview-style | Beginner to Intermediate | 3/5 | Yes |
| [freeCodeCamp Relational Databases](https://www.freecodecamp.org/learn/relational-database/) | PostgreSQL + database projects | Beginner to Intermediate | 4/5 | Yes |

*DataLemur has a free tier with a limited number of questions; full access
requires a paid plan.
