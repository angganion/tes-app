# Upgradeable Smart Contract for Real Estate Tokenization

An undergraduate thesis exploring an upgradeable smart contract for real estate tokenization with transfer restrictions based on KYC verification status.

## Mission

Create a safer path for tokenized real-estate ownership by connecting transfer rules to verifiable KYC state, while keeping upgrades explicit and controlled.

## Research focus

- Model transfer restrictions around KYC verification status.
- Separate upgrade authority from day-to-day asset transfers.
- Study how smart-contract boundaries affect transparency and future maintenance.
