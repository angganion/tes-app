# Gym Management System for RELOAD Gym

## Product scope

RELOAD Gym needed one system for the operational work that is usually spread across spreadsheets and disconnected tools. The product scope covered membership, classes, scheduling, and financial reporting.

## Development

The application uses Django for backend workflows and Vue.js for the client interface. I contributed across backend, frontend, and database layers while helping translate the product requirement document into 15+ actionable epics.

## Outcome

The result is a full-stack management flow that connects membership records to class operations and reporting. Documentation was kept alongside implementation so future changes could be discussed in terms of product behavior, not only screens.
