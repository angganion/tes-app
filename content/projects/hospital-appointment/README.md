# Hospital Appointment System

An appointment module for a full-stack hospital platform, designed around separate Spring Boot services.

## Mission

Keep patient scheduling dependable as the system grows, while protecting sensitive records behind clear service boundaries.

## What was shipped

- Architected separate services for patient records, scheduling, and notifications.
- Secured REST APIs with JWT and role-based access control.
- Configured the deployment pipeline with GitLab CI/CD and Docker.

## Loadout

`Java` `Spring Boot` `Microservices` `Docker` `JWT` `GitHub Actions`
