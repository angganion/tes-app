# Crowd Detection & Analytics Platform

A real-time computer vision system for detecting and tracking people in dense video streams.

## Mission

Build a live analytics surface that exposes useful crowd signals and stays readable while the scene changes quickly.

## What was shipped

- Fine-tuned a custom model for dense crowd environments.
- Added facial recognition to the live analytics workflow.
- Built a Vue.js dashboard for live counts, crowd density, and identity tracking.
- Fine-tuned the model on a custom crowd dataset for dense environments.
